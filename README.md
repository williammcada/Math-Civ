# Math Civ

**A WILLIAM MCADA PRODUCT**

Math Civ is a retro turn-based mathematics-and-civilization strategy game combining contextualized resource mathematics, city/economic decisions, tactical battle, and branching campaign outcomes.

## Canonical project record

**Repository:** `williammcada/Math-Civ`  
**Current state:** Playable foundational prototype with ongoing battle-length, gameplay-engagement, rounding/estimation, and mobile-compatibility revisions.  
**Handbook:** `williammcada/mcada-project-handbook`

The repository is the canonical home for the current source, permanent project brief, and approved version-specific change specifications. Chat history is working context rather than the permanent project record.
